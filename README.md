# Data Science Journey 🚀

Welcome to my Data Science repository — a structured, ever-growing collection of everything I'm learning on my path into Data Science, Machine Learning, and Deep Learning.

Created and maintained by **Khaled Ayman**.

This repo documents my journey starting from the absolute basics of **Python** and the **NumPy** library, all the way up to advanced **Deep Learning** concepts. Each topic lives in its own folder with notes, code, and practice notebooks.

---

## 📌 About This Repo

The goal of this repository is to:
- Track my personal progress in Data Science step by step.
- Serve as a reference I can come back to anytime.
- Share clean, organized material that could help other beginners follow a similar path.

The content is organized from **fundamentals → intermediate → advanced**, so you can either browse a specific topic or follow the repo in order like a learning roadmap.

---

## 🗂️ Repository Structure

Each major topic has its own dedicated folder:

```
data-science-journey/
│
├── 01-python-basics/          # Core Python fundamentals
├── 02-numpy/                  # Numerical computing with NumPy
├── 03-pandas/                 # Data manipulation & analysis
├── 04-data-visualization/     # Matplotlib, Seaborn, Plotly
├── 05-statistics-and-math/    # Statistics & math for Data Science
├── 06-machine-learning/       # ML algorithms & concepts
├── 07-deep-learning/          # Neural networks & Deep Learning
└── README.md
```

> Note: Folder names/order may be updated as the repo grows. New topics will always be added as a new numbered folder.
